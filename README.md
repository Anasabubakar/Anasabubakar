## About Me

```yaml
name:      Anas Masama
role:      Software engineer, founder of TeenovateX Labs
location:  Nigeria
works_on:  Agentic AI, mobile apps, Go and TypeScript backends, Stellar developer tools
cares_about: Clear architecture, honest trade offs, software that survives contact with users
```

I build **reliable systems and agentic AI products**. My work sits between systems design, applied AI and product engineering, and I would rather ship something that holds up than something that demos well.

I also run **[TeenovateX Labs](https://teenovatex.org)**, a nonprofit innovation hub that helps young Africans turn ideas into working products.

### Stellar Developer Tools

Seven tools, each shipped as an engine plus an app, with documentation on [GitBook](https://stellar-developer-tools.gitbook.io). Each one is built around a single question a Stellar team actually has to answer.

| Tool | The question it answers | Repos |
| ---- | ----------------------- | ----- |
| **AnchorTrace** | Why is this anchor payment stuck or disputed? Reconciles SEP-24 records against Stellar ledger evidence. | [sdk](https://github.com/Anchor-Trace/anchortrace-sdk) · [studio](https://github.com/Anchor-Trace/anchortrace-studio) |
| **EventParity** | Did changing my data source silently change my records? Compares Horizon, Stellar RPC and custom streams. | [engine](https://github.com/Event-Parity/eventparity-engine) · [studio](https://github.com/Event-Parity/eventparity-studio) |
| **ContractAtlas** | Does what is live on Soroban match what the protocol declares and audited? | [core](https://github.com/Contract-Atlas/contractatlas-core) · [studio](https://github.com/Contract-Atlas/contractatlas-studio) |
| **UpgradeLab** | Will this upgrade work against the state my app depends on? Published on crates.io. | [runner](https://github.com/Upgrade-Lab/upgradelab-runner) · [studio](https://github.com/Upgrade-Lab/upgradelab-studio) |
| **AuthMatrix** | Do two independent implementations compute the same Soroban authorization payload? | [core](https://github.com/Auth-Matrix/authmatrix-core) · [inspector](https://github.com/Auth-Matrix/authmatrix-inspector) |
| **ChargeGuard** | Does my deployment break the assumptions of the Stellar MPP charge flow? | [runner](https://github.com/Charge-Guard/chargeguard-runner) · [workbench](https://github.com/Charge-Guard/chargeguard-workbench) |
| **RailLab** | Can I make a SEP-24 anchor fail in the lab before the wallet fails for a user? | [engine](https://github.com/Rail-L-b/raillab-engine) · [workbench](https://github.com/Rail-L-b/raillab-workbench) |
